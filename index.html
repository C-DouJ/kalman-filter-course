为什么要滤波

一辆小车沿着直轨道往前开，你想知道它此刻到底在哪。手上有两条线索，可惜哪条都不完全可靠。

入门篇的范围

入门篇只用一个最简单的例子：状态是一个标量（小车的位置），模型不随时间变化（F、H、Q、R 都是常数，其中 F 是状态转移系数，H 是量测系数，在小车的例子里都等于 1）。这样可以把全部注意力放在「为什么」上。进阶篇会把所有结论推广到一般的线性时变系统：状态变成向量，F、H、Q、R 变成可以随时间变化的矩阵。公式会变复杂，但每一步的道理和这里完全一样。

两条线索

线索一：运动规律。你知道小车的速度大约是 1 m/s，所以每过 1 秒，它大概往前走 1 米。从起点开始一路推算，就能估出它的位置。这叫预测，也叫航位推算。问题是路面不平、轮子打滑，每一步都会差一点，而这一点点误差会一直累积下去。

线索二：传感器。小车上装了一个定位传感器（比如超声波测距或 GPS），每秒报告一次位置。问题是每次读数都带着随机噪声，忽大忽小。

看出了什么

  • 黄线（只信预测）像醉汉走路，越走越远，虚线边界按 √k 张开。
  • 红点（只信传感器）不会累积，但每一步都在 ±σR 附近乱跳。
  • 把 σw 调小、σR 调大，预测能撑更久；反过来，传感器更占优。
  • 蓝线是卡尔曼滤波，它比两条线索单独用都准。它做的事，就是每一步按「谁更靠谱」给两条线索分配权重。第 2 课讲这个权重怎么算，第 3 课把它一步步跑起来。

这里只要求扰动和噪声的均值为 0、方差分别是 Q 和 R，不要求它们服从高斯分布。方差是标准差的平方，所以 Q = σw2，R = σR2。网页里的仿真用的是高斯噪声，但后面推出的公式并不依赖这一点。

除了均值和方差，还需要三条「互不相关」的假设。后面每次写「方差相加」「交叉项为 0」，靠的都是它们：

  1. 噪声是白的。不同时刻的过程噪声互不相关，不同时刻的量测噪声也互不相关：E[wkwj] = 0，E[vkvj] = 0（k ≠ j）。这一步打滑了多少，和上一步打滑了多少无关。
  2. 过程噪声和量测噪声互不相关。对任意两个时刻都有 E[wkvj] = 0。路面怎么颠，和传感器怎么抖，是两回事。
  3. 两种噪声都和初始误差不相关。初始估计的误差 xˆ0 − x0 和之后所有的 wk、vk 都不相关。起点猜得准不准，不影响后面的噪声。

这里要求的是「不相关」，比「相互独立」弱；很多教材直接假设相互独立，那当然也满足。如果这些假设不成立，比如噪声前后相关（有色噪声），或者过程噪声和量测噪声相关，公式就需要修正，这是进阶篇的内容。

推导：为什么只信预测会越来越差

    结论

    在 kc 之前预测更准，之后传感器更准。但这只是二选一。下一课会看到，把两条线索按方差加权融合，结果比任何一条单独用都好。

Q = 0.5**2        # 运动扰动的方差（打滑、路面不平），σ_w = 0.5 m

rng = np.random.default_rng()

# 2. 生成真实位置和传感器读数（真实位置只有我们知道，滤波器看不到）
x_true = np.zeros(N)
for k in range(1, N):
    x_true[k] = x_true[k-1] + u*dt + rng.normal(0, np.sqrt(Q))
z = x_true + rng.normal(0, np.sqrt(R), N)

# 3. 两种“偷懒”的办法

# 4. 卡尔曼滤波：每一步按“谁更靠谱”把预测和读数加权（这五行怎么来的，第 2、3 课讲）
x_kf = np.zeros(N)
P = 0.0                           # 起点已知，所以初始误差方差为 0

    P = (1 - K) * P_pred          # 修正后的不确定性

    权重该怎么选

    此刻你手上有一个预测和一个读数，都不精确，说的数还不一样。最自然的想法是取个加权平均，问题是权重怎么选。这一课只用到期望和方差，不对噪声的分布形状做任何假设。

    写成加权修正

    把估计写成预测和读数的加权平均，再整理一下：

    加权修正

    K = 0 表示只信预测，K = 1 表示只信读数。括号里的差叫新息，是读数里预测没料到的那部分。估计就是从预测出发，往读数的方向挪 K 倍的新息。

    怎么评价一个 K 好不好？看估计误差的方差：方差越小，估计越稳。下面拖动 K，找出让方差最小的那一点。

    估计误差的方差随 K 的变化圆点是 5000 次随机实验的实测值
    理论 P(K) 预测误差的贡献 (1−K)²P⁻ 读数噪声的贡献 K²R 实验

    实测方差
    最优 K*

    看出了什么

    • 方差随 K 的变化是一条开口向上的抛物线。K 太小，预测误差占主导；K 太大，读数噪声占主导。最低点在两者之间。
    • 最低点的方差比 P⁻ 和 R 都小：把两个都不精确的判断融合起来，得到一个更精确的判断。
    • 把读数噪声调大，K* 往左移，更相信预测；把预测误差调大，K* 往右移，更相信读数。

    推导：最优的 K

      这个结论依赖高斯吗？

      回头看推导，只用到了均值、方差和「不相关」，从头到尾没有提噪声长什么样。下面用实验验证：四种噪声的均值都是 0、方差也都一样，只是分布的形状不同。每种做 5000 次实验，看实测方差是否还落在同一条抛物线上。预测误差和读数噪声的大小沿用上面的设置。

      理论 P(K)，和分布无关 这种分布下的实验
      在最优 K* 处，5000 次实验的估计误差
      K* 处的估计误差 只信预测（K = 0）时的误差
      • 四种分布的实验点都贴着同一条抛物线，最优 K 也一样。线性最小方差的结论不依赖高斯假设。
      • 但直方图的形状跟着噪声变。切到「重尾」：绝大多数误差很小，少数却非常大。方差公式照样成立，可这种时候，能识别并丢掉野值的非线性方法可以做得更好。这是进阶篇鲁棒滤波要解决的问题。
      只用了三条假设

      预测误差和读数噪声的均值都是 0；它们的方差 P⁻ 和 R 已知；两者不相关。没有用到高斯。这样得到的估计叫线性最小方差估计：在预测和读数的所有线性组合里，它的误差方差最小。顺便一提，「不相关」是比「独立」更弱的条件。

      「两者不相关」不是凭空假设的，它来自第 1 课的三条假设：预测误差是由初始误差、到目前为止的过程噪声和之前的量测噪声累积而成的，而这一步的量测噪声和它们全都不相关。第 3 课推导递推公式时会逐条用到。

      对应到卡尔曼滤波

      给每个量加上时间下标 k，这一课的结果就是卡尔曼滤波「更新」的三步。下一课把它和「预测」的两步串成完整的循环。

    if kind == '重尾':            # 95% 的时候噪声很小，5% 的时候放大 10 倍

function w = unit_noise(kind, n)
    % 均值为 0、方差为 1，但形状各不相同的几种噪声
    switch kind
        case '高斯'
            w = randn(n, 1);
        case '均匀'
            w = (2 * rand(n, 1) - 1) * sqrt(3);
        case '双峰'
            w = 0.9 * sign(rand(n, 1) - 0.5) + sqrt(0.19) * randn(n, 1);
        case '重尾'               % 95% 的时候噪声很小，5% 的时候放大 10 倍

            w = randn(n, 1) .* (1 + 9 * big) / sqrt(5.95);
    end
end

      单步跑一遍

      把前两课拼起来：预测让不确定性变大，观测让它变小，一步接一步地循环。下面这辆小车会陪你把五个公式挨个算一遍。

      两个阶段：预测和更新

      卡尔曼滤波的每一步都分成两个阶段，交替进行。

      预测（也叫时间更新）：第 k 步的读数还没到。只靠运动模型，把上一步的估计往前推到当前时刻，得到先验估计 和它的误差方差 。上标 − 的意思是「还没用上第 k 步的读数」。小车在这段时间里又受了一次扰动，所以不确定性变大。

      更新（也叫量测更新）：读数 到了。用它修正先验估计，得到后验估计 和它的误差方差 。用上了新的信息，所以不确定性变小。

      阶段用到的信息输入输出不确定性

      后验估计接着成为下一步预测的起点，如此循环。有的教材和论文把先验、后验写成 xˆk|k−1 和 xˆk|k，竖线后面表示「用到了截至哪一步的读数」，意思相同。

      误差方差的锯齿前 12 步：预测让它升高，更新让它降低
      预测：P⁻ = P + Q，升高 更新：P = (1 − K)P⁻，降低 两次读数之间

              贝叶斯视角：高斯给了我们什么

              前三课只追踪两个数：估计是多少，方差有多大。这一课换一种更完整的描述，直接追踪「小车在每个位置的可能性有多大」，也就是整个概率分布。这条路推出的还是同一组公式，但它能回答一个前面回答不了的问题：卡尔曼滤波到底是不是最好的？

              用一条曲线表示「我知道多少」

              我们对小车位置的认识，可以画成一条曲线 p(x)，叫概率密度：曲线在哪里高，小车就更可能在哪里；曲线下的总面积永远是 1。曲线越窄越高，说明越有把握。

              最常用的是高斯分布 N(μ, σ2)，也就是钟形曲线：μ 是最可能的位置，σ 是不确定的程度。它只用两个数就能完全确定，这一点后面会起决定性的作用。

              贝叶斯公式：读数怎样改变认识

              读数到来之前，我们已经有一个认识，来自预测。读数到来之后，认识应该怎么变？贝叶斯公式给出了唯一合理的答案。它涉及三条曲线：

              • 先验 p(x)：读数到来之前的认识。在滤波里，它就是预测的结果。
              • 似然 p(z | x)：假如小车真的在 x，读到 z 的可能性有多大。因为 z = x + v，读到 z 就意味着噪声恰好等于 z − x，所以似然就是噪声的密度在 z − x 处的值。
              • 后验 p(x | z)：看到读数之后的认识。
              贝叶斯公式

              这里有一个容易绕晕的地方：读数 z 已经是一个确定的数了，所以要把似然看成 x 的函数，它回答的是「哪些位置能解释这个读数」。噪声是高斯时，它是一条以读数为中心、宽度为 σR 的钟形曲线。分母 p(z) 和 x 无关，只负责把面积调回 1。

              所以操作很简单：两条曲线逐点相乘，再归一化。相乘的道理是：一个位置要可信，必须既符合预测，又能解释读数。只要有一方认为它几乎不可能，乘积就接近 0。

              先验（预测）N(μ₁, σ₁²) 似然（读数）N(μ₂, σ₂²) 后验 N(μ, σ²)

              看出了什么

              • 后验永远比先验和似然都窄：用上读数之后，总是更有把握。
              • 后验的峰落在两者之间，靠向更窄、更准的那一条。两条一样宽时正好取中点。
              • 两条高斯曲线相乘，结果看起来还是一条钟形曲线。这不是巧合，下面就来证明。

              推导：更新就是两个高斯相乘

                预测在贝叶斯里是什么

                更新是「相乘」，那预测呢？预测要回答的是：已知上一步小车位置的分布，再走一步之后，位置的分布是什么？

                  所以，卡尔曼滤波是什么

                  预测用全概率公式，更新用贝叶斯公式，两步交替进行，这套做法叫贝叶斯滤波。它对任何分布、任何模型都成立，是最一般的答案：一般情形下，预测要按状态转移概率，把上一步各种可能状态的贡献加起来；在本例中，因为小车只是平移再叠加一个扰动，这一步恰好是卷积。麻烦在于，一般情况下分布的形状会越变越复杂，没法用有限的几个数存下来。

                  线性模型加高斯噪声是一个特例。在这个特例里：

                  阶段贝叶斯滤波（一般情形）线性 + 高斯时
                  预测按状态转移概率，把上一步各种可能状态的贡献加起来（本例中是平移再卷积）高斯卷积高斯还是高斯：均值加 uΔt，方差加 Q
                  更新先验乘以似然，再归一化高斯乘高斯还是高斯：均值和方差按 ③ ④ ⑤ 变化

                  只要初始分布是高斯，之后每一步的分布就永远是高斯。而高斯分布只需要均值和方差两个数就能完全确定，所以我们不必追踪整条曲线，只追踪这两个数就够了。这两个数的递推公式，正是第 3 课的五个公式。

                  这一课的核心结论

                  卡尔曼滤波是贝叶斯滤波在「线性模型 + 高斯噪声」下的精确解。第 3 课图里的钟形曲线，在高斯假设下就是真正的后验分布，不只是示意。

                  为什么报后验的均值：最小均方误差估计

                  后验是一整条曲线，可我们最终要报一个数。报哪个？这取决于怎么评价「报得好不好」。最常用的标准是均方误差：误差的平方的平均值。它越小越好；让它最小的估计叫最小均方误差估计，英文缩写 MMSE。均方根误差 RMSE 是它的平方根，让其中一个最小，另一个也最小。

                  推导：为什么是均值

                    换一个评价标准，答案会变

                    均值是「平方误差」这个标准下的最优。如果改成让误差绝对值的平均最小，最优的是后验的中位数；如果想报「最可能的位置」，就是曲线的最高点，叫极大后验估计（MAP），下一课专门讲它。高斯分布左右对称、只有一个峰，这三个数重合，所以高斯时不用纠结选哪个标准。

                    现在可以完整地回答了。推出公式不需要高斯假设，第 2 课已经证明过。高斯假设给的是三样别的东西：

                    • 更强的最优性。没有高斯假设：在所有线性估计里方差最小。有高斯假设：在所有估计里均方误差最小，任何非线性的办法都不可能更好。
                    • 完整的分布。只知道方差时，能说的很有限：由切比雪夫不等式，误差落在 ±2σ 以内的概率至少是 75%。知道是高斯以后，这个概率就是 95%，可以给出准确的置信区间。
                    • 两个数就够用。分布永远保持高斯，所以只存均值和方差，就没有丢掉任何信息。

                    反过来，噪声明显不是高斯时，卡尔曼滤波仍然是最好的线性滤波器，但还有改进的空间。进阶篇的粒子滤波直接用数值方法近似整个后验；鲁棒滤波则专门对付重尾噪声和野值。

                    高斯假设不是推出卡尔曼滤波的前提，它决定的是这个公式有多好。

                    极大后验视角：找后验的最高点

                    上一课最后提到，除了报后验的均值，还可以报后验曲线的最高点，也就是「最可能的位置」。这叫极大后验估计，英文缩写 MAP。沿着这条路走，估计变成了一个求最值的优化问题；取一次对数，它就是加权最小二乘。这个视角还天然告诉我们，遇到离谱的读数该怎么办。

                    从后验的最高点到最小二乘

                      加权最小二乘

                      J 的两项可以这样读：给每个候选位置打一个「矛盾分」，离预测越远扣分越多，离读数越远也扣分越多。扣分用各自的方差做分母，所以越不准的线索，偏离它的代价越小。极大后验估计就是矛盾分最低的位置。

                      顺带一提，这个最小化问题本身并不依赖高斯：即使不谈概率分布，也可以直接把 J 当作出发点，这时它叫加权最小二乘，答案完全相同。高斯假设的作用，是告诉我们它同时也是后验的最高点。

                      两根弹簧

                      这个最小化问题有一个很直观的物理模型：小车被两根弹簧拉着，一根拴在预测位置，一根拴在读数位置，劲度分别是 1/P⁻ 和 1/R。弹簧的弹性势能和拉伸量的平方成正比，所以 J 就是两根弹簧的总势能，小车停下来的平衡点就是 J 的最小点。

                      两根弹簧拉着小车弹簧越粗，劲度越大，也就是那条线索越准
                      后验 p(x | z)正比于 exp(−J/2)
                      取负对数：J(x)后验的最高点，正对着 J 的最低点
                      偏离预测的代价 偏离读数的代价 总代价 J(x) 最小点 = 估计
                      平衡点 xˆ
                      总劲度 1/P⁻ + 1/R
                      融合后的方差 P
                      被读数拽离预测的距离

                      看出了什么

                      • 后验的最高点、J 的最低点、弹簧的平衡点，三者是同一个位置。求最大的后验和求最小的 J 是一回事。
                      • 这个位置就是第 2 课的 xˆ。劲度大的弹簧，也就是更准的那条线索，把小车拉得更近。
                      • 两根弹簧一起拉，总劲度是两者相加：1/P⁻ + 1/R。总劲度越大，小车越难被推离平衡点，这就是「精度相加」。融合后的方差 P 就是总劲度的倒数。
                      • 点「读数离谱」，再在两种弹簧之间切换。普通弹簧拉得越长、力越大，一个差了 8 米的读数能把小车拽走 4 米。Huber 弹簧拉过一定长度后，力就不再增加，小车只被拽走 1.3 米左右。把平方损失换成对野值不敏感的损失，就是基于 M 估计的鲁棒滤波的出发点。Huber 损失就是 M 估计里最常用的一种。
                      • 从极大后验的角度看，换弹簧就是换噪声模型：损失函数是噪声密度的负对数。平方损失对应高斯噪声；Huber 损失对应一种中间像高斯、两边尾巴更重的噪声。认为噪声的尾巴越重，损失增长得就越慢，估计对野值也就越不敏感。切换到 Huber 弹簧时，上面的后验曲线也跟着变了。

                        第 6 课 · 几何视角

                        误差最小时，为什么与新息垂直？

                        小车只沿一条直轨行驶，误差怎么还会和新息成直角？先看同一个位置误差在几种可能情形下各取什么值。把这些值排成一行，我们就能给误差画一根箭头，也能看见调节增益时它怎样变短、又怎样变长。

                        怎样把随机变量看成向量？

                        为了把所有可能的取值都写下来，先给小车设四种等可能的情形。沿用前几课的约定，预测误差取「预测位置减真实位置」，量测噪声取「量测位置减真实位置」。表中正数表示偏高，负数表示偏低。

                        小车在四种等可能情形下的误差（米）
                        可能情形甲乙丙丁
                        预测误差 e−+2+2−2−2
                        量测噪声 v+1−1+1−1

                        竖着看甲这一列，这一趟预测偏高 2 米，量测偏高 1 米。横着看预测误差这一行，同一个变量在甲、乙、丙、丁四种情形下取值分别是 (2, 2, −2, −2) 米。按这个顺序排列，它就是一个四维向量，每个坐标对应一种可能情形。

                        现在算第 3 课的新息 r。量测值和预测位置都减去同一个真实位置，两者的差不变，所以 r = v − e−。甲这一列给出 1 − 2 = −1 米，乙这一列给出 −1 − 2 = −3 米。四列逐项相减，新息就是 (−1, −3, 3, 1) 米。再乘以增益 K，每个坐标都乘以 K。随机变量的减法和数乘就这样变成了向量运算。

                        误差箭头的长度和夹角怎么算？

                        假如把甲这一列拆成两列，取值完全相同，概率各占原来的一半，小车的误差并没有变。为了让箭长也保持不变，计算两根向量的内积时，要把同一情形的两个值相乘，再按各自情形的概率取平均。原表四种情形等可能，四项乘积相加再除以 4 就是这个平均。

                        ⟨e−,e−⟩=4+4+4+44=4
                        长度的平方（平方米）

                        自己与自己的内积是长度的平方，所以预测误差的箭长是 √4 = 2 米。同样算，量测噪声的箭长是 1 米。把两行配对相乘再平均，得到 (2 − 2 − 2 + 2) / 4 = 0。两根非零向量的内积为零，夹角就是直角。它们虽然各有四个坐标，却只张成一个平面，所以能按这个长度和角度完整地画在纸上。

                        更一般地，对于二阶矩有限的随机变量 a、b，把按概率取平均写成期望，内积就是 ⟨a, b⟩ = E[ab]。表中的误差均值为零。若均值不为零，画箭头前先把各变量减去自己的均值。这样，箭长是标准差，内积是协方差。把内积除以两根非零箭头的长度之积，得到的就是夹角的余弦，也就是相关系数 ρ。

                        换两个可以调节相关性的变量 a、b。散点图的一个点对应一次采样，向量图的一根箭头对应一个变量。如果已知 b，想用它的某个倍数 cb 来估计 a，图中的黄线段就是最佳的 cb，红色虚线是剩下的误差。试着把相关系数 ρ 从正数拖到负数。

                        300 次采样 · 横轴是 b，纵轴是 a
                        总体的两个向量 · 箭长是标准差，夹角由 ρ 决定
                        向量 a 向量 b a 在 b 上的投影 c·b 剩下的误差 a − c·b

                        剩余误差的方差

                        对比 +0.60 和 −0.60。散点图中的黄线从上斜变成下斜，向量图上的投影也翻到了原点另一侧。相关为正时，b 增大，就该把对 a 的估计调高。相关为负时，就该调低。两次红色虚线一样长，说明剩余误差的方差相同。再调到 0，两根箭头垂直，沿 b 的投影缩成了一个点。

                        展开推导 · 只知道 b，乘以几最合适？

                        让 c 取遍实数，cb 的端点便扫过一条直线。要用 cb 估计 a，剩余误差是 a − cb。它最短时垂直于 b，所以 ⟨a − cb, b⟩ = 0。若 b 的方差大于零，解得

                        c=Cov(a,b)Var(b)
                        最佳线性倍数

                        降下去的方差占原方差的 ρ²，留下来的占 1 − ρ²。这张图里 a 的标准差为 1.5，当 |ρ| = 0.6 时，剩余方差是 1.5² × (1 − 0.6²) = 1.44。

                        这里的最优限于线性估计。让 b 等概率取 −1、0、1，再令 a = b² − 2/3。两者协方差为零，用 cb 估计 a 的最佳倍数是 0。可是知道 b 后，只要平方再减去 2/3，就能精确算出 a。

                        拖动增益，找出最短的蓝箭头

                        回到第 5 课的两根弹簧。那一次预测位置是 10 米，量测值是 12 米。这次会用到的是预测误差和量测噪声的标准差（2 米和 1 米），以及两者不相关的条件。开头用四种情形具体算过这组长度和夹角。换一种误差分布，只要这三个条件相同，画出来的仍是同一幅图。

                        如果知道预测偏了多少，理想的修正量就是 −e−。实际能算出来的是新息 r，我们只能选它的一个倍数 Kr 来修正。把第 3 课的位置更新式两边都减去同一个真实位置 x，便能看清修正以后还剩多少误差。

                        xˆ−x=(xˆ−−x)+Kre=e−+Kr
                        估计位置减真实位置

                        从原点沿黄箭头走到预测误差 e− 的尖端。从那里指向红箭头尖端的向量是 v − e− = r，沿它走 K 倍，走过的那一段就是修正量 Kr。从原点连到新端点的蓝箭头正好是这两段的和，因此代表更新后的误差 e。在本例中误差的均值为零，蓝箭头的长度平方就是多次实验的均方误差。

                        把 K 拉到 0，蓝箭头与黄箭头重合。再慢慢拉到 1，蓝箭头会走到与红箭头重合的位置。蓝箭头在哪儿最短？它这时和哪条线垂直？先自己找，再点「跳到最优 K」核对。

                        预测误差、量测噪声与更新后的误差修正量 Kr 从黄箭头尖端出发，更新误差 e 从原点出发
                        预测误差 e⁻ 量测噪声 v 新息 r = v − e⁻ 所在的直线 修正量 K·r 更新误差 e = e⁻ + K·r
                        更新误差方差 ‖e‖²
                        ‖K·r‖² = K²(P⁻ + R)
                        e 和 r 的夹角
                        内积 ⟨e, r⟩
                        最优 K*

                        蓝箭头的起点固定，尖端沿新息所在的直线移动。从一点到直线，垂线段最短，所以调到垂足时，更新误差与新息垂直。用默认参数，K 从 0.4 增至 0.8，更新误差方差从 1.60 降到 0.80 平方米。再走到 K = 1，误差方差又回到 1 平方米。

                        11.6 米的位置，0.89 米的标准差

                        在第 5 课那一次量测中，新息是 12 − 10 = 2 米。取 K = 0.8，修正量就是 1.6 米，更新后的位置是 11.6 米。图上蓝箭头的长度 √0.8 ≈ 0.89 米描述的是在相同误差条件下反复做实验，更新误差的标准差。

                        在垂足上读出增益和方差

                        预测误差方差记作 P−，量测噪声方差记作 R。用 r = v − e− 展开内积。因为 ⟨e−, v⟩ = 0，有 ⟨e−, r⟩ = −P−，而 ⟨r, r⟩ = P− + R。将它们代入垂足条件 ⟨e− + Kr, r⟩ = 0，就能解出增益。

                        −P−+K(P−+R)=0K∗=P−P−+R
                        垂足处的增益

                        在垂足处，预测误差、修正量和更新误差围成直角三角形。斜边的长度平方是更新前的方差 P−。减去修正量的长度平方，余下的就是更新后的方差 P。

                        P−=‖K∗r‖2+PP=(1−K∗)P−
                        仅在垂足处使用此分解

                        用默认参数验算，4 = 3.2 + 0.8，单位都是平方米。还可以回到开头的四种等可能情形，直接用 e = e− + 0.8r 逐列算出更新误差 (1.2, −0.4, 0.4, −1.2) 米。四项平方取平均，正好也是 0.80 平方米。

                        如果 K 多走或少走一点，会损失多少精度？

                        从垂足再沿虚线走一步，比如从 0.8 走到 0.9。多走的那段与最短的蓝箭头垂直，又构成一个直角三角形。因此任意增益对应的误差方差都可以拆成两项。

                        P(K)=P(K∗)+(P−+R)(K−K∗)2
                        增益偏离最优值的代价

                        在本例里，多走 0.1 和少走 0.1 付出同样的代价，都是 5 × 0.1² = 0.05 平方米。拖到 0.7 和 0.9，两次都会读到 0.85 平方米。手动选增益时，也可直接用 P(K) = (1 − K)²P− + K²R 验算。

                        收到第 101 次量测，为什么不用重算前 100 个权重？

                        先看两次量测就够了。让小车停在原地。初始预测是 10 米，误差方差是 4 平方米；传感器独立测两次，每次的噪声方差都是 1 平方米，量测噪声与初始误差也不相关。第一次量到 12 米，更新后的位置是 11.6 米，误差方差是 0.8 平方米。

                        第二次量到 12.5 米。光看上一步留下的两个数，就能完成更新：用 11.6 米算新息，得到 12.5 − 11.6 = 0.9 米；用 0.8 平方米算增益，得到 0.8 / (0.8 + 1) = 4/9。这次修正了 0.9 × 4/9 = 0.4 米，位置估计从 11.6 米变成了 12 米。

                        第一次量测的 12 米，在第二次估计里还占多少？把刚才的更新式展开：

                        xˆ2=xˆ1+49(z2−xˆ1)=59xˆ1+49z2

                        第一步的 11.6 米里，初始预测占 1/5，第一次量测占 4/5。现在把 11.6 米整个乘以 5/9，里面的两份权重就一起变了：

                        第一次量测的权重确实从 4/5 变成了 4/9，因为 (5/9) × (4/5) = 4/9。如果像第 5 课那样，把三份信息拿出来一次性按方差的倒数加权，也会得到右栏的 1∶4∶4。不用重算，是说不用回头逐个求旧权重；它们对最终估计的影响仍会随新量测改变。

                        回到运动的小车。前 100 次量测对应的是过去各时刻的位置，不能照搬静止时的加权平均。先按运动模型把上一步的位置估计和误差方差推到第 101 步。既然这已经是历史量测给出的最佳线性预测，单靠旧量测就没法再减小均方误差。现在用新量测减去预测，得到新息；沿这个方向走到上图的垂足，就能达到用全部 101 次量测作线性估计的同样精度。下面来证明最后这一句。

                        展开证明：如果把前 100 个权重也放开，还能更准吗？

                        我们比较两种做法：一种从原预测出发，只沿新息修正；另一种可以给全部 101 次量测任意配权。要证明的是，后一种做法再怎么选，也不能把误差变得更小。下面的符号都指第 101 步，省去时间下标。

                        把两种做法放到同一个式子里

                        先看可以任意配权的做法。若它给本次量测 z 的权重是 K，那么它给出的位置一定是「某个旧量测组合 + Kz」。这里的旧组合可以带一个常数，因而也能包含已知位移。

                        现在代入 z=xˆ−+r。其中的预测 xˆ− 本来就能由历史量测和已知位移算出，所以 K 倍的预测可以并入旧组合。把合并后的旧组合与原预测的差记作 d，就得到：

                        任意配权的估计=xˆ−+Kr+d

                        先固定 K。取 d = 0，得到图中只沿新息修正的估计。如果还想给第 37 次量测多一点权重，或者把前 100 个权重全调一遍，多出来的改动都算在 d 里。问题变成了：加上这段 d，能把蓝箭头缩短吗？

                        看多出来的这段，和蓝箭头成什么角

                        预测误差 e− 与任何这样的 d 都垂直。理由是：如果它在某个旧方向上还有分量，就能把预测沿这个方向稍微挪一点，让误差更短。这和“它已经是根据历史量测作出的最佳线性预测”矛盾。在本课的小车模型里，上一步的最佳估计加上已知位移就是这个预测，因为新增的过程噪声均值为零，也与历史量测不相关。

                        再看新息。本次量测噪声 v 同样均值为零，与历史量测不相关，所以 v 也与 d 垂直。由 r=v−e−，r 与 d 也垂直。于是无论 K 取多少，蓝箭头 e−+Kr 始终垂直于多出来的这段 d。

                        用一次勾股定理就能比较两种做法。左边是额外调整旧权重后的误差长度平方，右边第一项是只沿新息更新的误差长度平方：

                        ‖e−+Kr+d‖2=‖e−+Kr‖2+‖d‖2

                        最后一项最小是零，取 d = 0 就能达到。这样一来，全部 101 个权重的选择只剩下沿新息走多远。把 K 调到上一张互动图的垂足，得到的就是卡尔曼增益。

                        这里比较的是量测的线性组合（允许加常数）。第 4 课还允许用量测的非线性函数；当状态与量测联合高斯时，两种范围下的最优估计相同。

                        没有位置真值，怎样检查新息与过去是否相关？

                        在实际导航中，我们能记录预测位置和传感器量测值，通常却拿不到每一刻的位置真值。好在相减就能得到新息。历史新息是历史量测的线性组合（中心化后），所以本次新息若与历史量测正交，也就与之前各步的新息不相关。这给了我们一项可以直接用数据检查的预期。

                        让小车重新运动起来，模拟两万步。每步平均前进 1 米，真实过程噪声方差 Q = 0.25 平方米，量测噪声方差 R = 4 平方米。下面四组滤波都用同一串量测值，只改变滤波器填入的参数。

                        先看相邻两步的新息。Q 设得太小，模型预测的分量占得重，每次纠正得少，下一步往往还要朝同一边纠。Q 设得太大，估计容易跟着一次偏高的量测走，下一步又容易往回调。再看新息的大小，把实际记录的新息方差和滤波器预测的方差 Sk = Pk− + R 作比较。

                        怎样把不同时刻的新息放在同一尺度上？

                        各步新息的预测方差可能不同，尤其是在滤波刚开始时。把每一步的新息除以该步的预测标准差，得到标准化新息。在模型成立时，这个序列的均值为零、方差为一，不同时刻互不相关，这就是这里所说的「白」。有限样本的相关系数会有起伏。检查时还能把两步、三步等多个间隔一起看。若各量联合高斯，不同时刻的新息还相互独立。
