为什么要滤波

一辆小车沿着直轨道往前开，你想知道它此刻到底在哪。手上有两条线索，可惜哪条都不完全可靠。

入门篇的范围

入门篇只用一个最简单的例子：状态是一个标量（小车的位置），模型不随时间变化（F、H、Q、R 都是常数，其中 F 是状态转移系数，H 是量测系数，在小车的例子里都等于 1）。这样可以把全部注意力放在「为什么」上。进阶篇会把所有结论推广到一般的线性时变系统：状态变成向量，F、H、Q、R 变成可以随时间变化的矩阵。公式会变复杂，但每一步的道理和这里完全一样。

两条线索

线索一：运动规律。你知道小车的速度大约是 1 m/s，所以每过 1 秒，它大概往前走 1 米。从起点开始一路推算，就能估出它的位置。这叫预测，也叫航位推算。问题是路面不平、轮子打滑，每一步都会差一点，而这一点点误差会一直累积下去。

线索二：传感器。小车上装了一个定位传感器（比如超声波测距或 GPS），每秒报告一次位置。问题是每次读数都带着随机噪声，忽大忽小。

镜头跟着小车走上面一排是各种办法给出的位置，下面是读数

看出了什么

  • 黄线（只信预测）像醉汉走路，越走越远，虚线边界按 √k 张开。
  • 红点（只信传感器）不会累积，但每一步都在 ±σR 附近乱跳。
  • 把 σw 调小、σR 调大，预测能撑更久；反过来，传感器更占优。
  • 蓝线是卡尔曼滤波，它比两条线索单独用都准。它做的事，就是每一步按「谁更靠谱」给两条线索分配权重。第 2 课讲这个权重怎么算，第 3 课把它一步步跑起来。

这里只要求扰动和噪声的均值为 0、方差分别是 Q 和 R，不要求它们服从高斯分布。方差是标准差的平方，所以 Q = σw2，R = σR2。网页里的仿真用的是高斯噪声，但后面推出的公式并不依赖这一点。

除了均值和方差，还需要三条「互不相关」的假设。后面每次写「方差相加」「交叉项为 0」，靠的都是它们：

  1. 噪声是白的。不同时刻的过程噪声互不相关，不同时刻的量测噪声也互不相关：E[wkwj] = 0，E[vkvj] = 0（k ≠ j）。这一步打滑了多少，和上一步打滑了多少无关。
  2. 过程噪声和量测噪声互不相关。对任意两个时刻都有 E[wkvj] = 0。路面怎么颠，和传感器怎么抖，是两回事。
  3. 两种噪声都和初始误差不相关。初始估计的误差 x̂0 − x0 和之后所有的 wk、vk 都不相关。起点猜得准不准，不影响后面的噪声。

这里要求的是「不相关」，比「相互独立」弱；很多教材直接假设相互独立，那当然也满足。如果这些假设不成立，比如噪声前后相关（有色噪声），或者过程噪声和量测噪声相关，公式就需要修正，这是进阶篇的内容。

推导：为什么只信预测会越来越差

    结论

    在 kc 之前预测更准，之后传感器更准。但这只是二选一。下一课会看到，把两条线索按方差加权融合，结果比任何一条单独用都好。

    自己跑一遍

    下面的代码生成同样的小车和读数，算出两种偷懒办法和卡尔曼滤波的误差。卡尔曼滤波那五行先照着用，它们怎么来的是后面两课的内容。代码每次运行都会生成新的随机数，和网页里的也不一样，具体数字会有差别，但规律相同。

    需要 numpy、matplotlib
    import numpy as np
import matplotlib.pyplot as plt
plt.rcParams['font.sans-serif'] = ['SimHei', 'Microsoft YaHei', 'PingFang SC', 'Noto Sans CJK SC']
plt.rcParams['axes.unicode_minus'] = False

# 1. 设定：小车沿直线开，名义速度 u = 1 m/s，每 Δt = 1 s 读一次传感器
N, dt, u = 200, 1.0, 1.0
Q = 0.5**2        # 运动扰动的方差（打滑、路面不平），σ_w = 0.5 m
R = 2.0**2        # 传感器噪声的方差，σ_R = 2 m
rng = np.random.default_rng()

# 2. 生成真实位置和传感器读数（真实位置只有我们知道，滤波器看不到）
x_true = np.zeros(N)
for k in range(1, N):
    x_true[k] = x_true[k-1] + u*dt + rng.normal(0, np.sqrt(Q))
z = x_true + rng.normal(0, np.sqrt(R), N)

# 3. 两种“偷懒”的办法
x_dr = np.arange(N) * u * dt      # 只信预测：从起点按名义速度一路推算
x_meas = z                        # 只信传感器：读数是多少就是多少

# 4. 卡尔曼滤波：每一步按“谁更靠谱”把预测和读数加权（这五行怎么来的，第 2、3 课讲）
x_kf = np.zeros(N)
P = 0.0                           # 起点已知，所以初始误差方差为 0
for k in range(1, N):
    x_pred = x_kf[k-1] + u*dt     # 预测位置
    P_pred = P + Q                # 预测的不确定性
    K = P_pred / (P_pred + R)     # 给读数的权重
    x_kf[k] = x_pred + K * (z[k] - x_pred)   # 用读数修正
    P = (1 - K) * P_pred          # 修正后的不确定性

for name, est in [('只信预测', x_dr), ('只信传感器', x_meas), ('卡尔曼滤波', x_kf)]:
    rmse = np.sqrt(np.mean((est - x_true)**2))
    print(f'{name}: RMSE = {rmse:.2f} m')
print(f'理论交叉点 k_c = R/Q = {R/Q:.0f} 步')

k = np.arange(N)
plt.plot(k, x_dr - x_true, label='只信预测的误差')
plt.plot(k, z - x_true, '.', label='只信传感器的误差')
plt.plot(k, x_kf - x_true, lw=2, label='卡尔曼滤波的误差')
plt.plot(k, np.sqrt(k*Q), 'k:', k, -np.sqrt(k*Q), 'k:')
plt.axhline(0, color='gray', lw=0.5)
plt.xlabel('k（步）'); plt.ylabel('误差 (m)'); plt.legend(); plt.show()

    权重该怎么选

    此刻你手上有一个预测和一个读数，都不精确，说的数还不一样。最自然的想法是取个加权平均，问题是权重怎么选。这一课只用到期望和方差，不对噪声的分布形状做任何假设。

    写成加权修正

    把估计写成预测和读数的加权平均，再整理一下：

    加权修正

    K = 0 表示只信预测，K = 1 表示只信读数。括号里的差叫新息，是读数里预测没料到的那部分。估计就是从预测出发，往读数的方向挪 K 倍的新息。

    怎么评价一个 K 好不好？看估计误差的方差：方差越小，估计越稳。下面拖动 K，找出让方差最小的那一点。

    估计误差的方差随 K 的变化圆点是 5000 次随机实验的实测值
    理论 P(K) 预测误差的贡献 (1−K)²P⁻ 读数噪声的贡献 K²R 实验
    当前 K 的理论方差
    实测方差
    最优 K*
    最小方差 P

    看出了什么

    • 方差随 K 的变化是一条开口向上的抛物线。K 太小，预测误差占主导；K 太大，读数噪声占主导。最低点在两者之间。
    • 最低点的方差比 P⁻ 和 R 都小：把两个都不精确的判断融合起来，得到一个更精确的判断。
    • 把读数噪声调大，K* 往左移，更相信预测；把预测误差调大，K* 往右移，更相信读数。

    推导：最优的 K

      这个结论依赖高斯吗？

      回头看推导，只用到了均值、方差和「不相关」，从头到尾没有提噪声长什么样。下面用实验验证：四种噪声的均值都是 0、方差也都一样，只是分布的形状不同。每种做 5000 次实验，看实测方差是否还落在同一条抛物线上。预测误差和读数噪声的大小沿用上面的设置。

      理论 P(K)，和分布无关 这种分布下的实验
      在最优 K* 处，5000 次实验的估计误差
      K* 处的估计误差 只信预测（K = 0）时的误差
      • 四种分布的实验点都贴着同一条抛物线，最优 K 也一样。线性最小方差的结论不依赖高斯假设。
      • 但直方图的形状跟着噪声变。切到「重尾」：绝大多数误差很小，少数却非常大。方差公式照样成立，可这种时候，能识别并丢掉野值的非线性方法可以做得更好。这是进阶篇鲁棒滤波要解决的问题。
      只用了三条假设

      预测误差和读数噪声的均值都是 0；它们的方差 P⁻ 和 R 已知；两者不相关。没有用到高斯。这样得到的估计叫线性最小方差估计：在预测和读数的所有线性组合里，它的误差方差最小。顺便一提，「不相关」是比「独立」更弱的条件。

      「两者不相关」不是凭空假设的，它来自第 1 课的三条假设：预测误差是由初始误差、到目前为止的过程噪声和之前的量测噪声累积而成的，而这一步的量测噪声和它们全都不相关。第 3 课推导递推公式时会逐条用到。

      对应到卡尔曼滤波

      给每个量加上时间下标 k，这一课的结果就是卡尔曼滤波「更新」的三步。下一课把它和「预测」的两步串成完整的循环。

      自己跑一遍

      用四种形状完全不同的噪声各做 10 万次实验，验证方差曲线和最优 K 都与分布形状无关。

      MATLAB 需要 R2018b 以上
      import numpy as np
import matplotlib.pyplot as plt
plt.rcParams['font.sans-serif'] = ['SimHei', 'Microsoft YaHei', 'PingFang SC', 'Noto Sans CJK SC']
plt.rcParams['axes.unicode_minus'] = False

P_pred, R = 2.0**2, 1.0**2        # 预测误差的方差、读数噪声的方差
n = 100_000                       # 每种噪声做 10 万次实验
rng = np.random.default_rng()

def unit_noise(kind, size):
    """均值为 0、方差为 1，但形状各不相同的几种噪声"""
    if kind == '高斯':
        return rng.standard_normal(size)
    if kind == '均匀':
        return rng.uniform(-np.sqrt(3), np.sqrt(3), size)
    if kind == '双峰':
        return rng.choice([-0.9, 0.9], size) + np.sqrt(0.19) * rng.standard_normal(size)
    if kind == '重尾':            # 95% 的时候噪声很小，5% 的时候放大 10 倍
        big = rng.random(size) < 0.05
        return rng.standard_normal(size) * np.where(big, 10, 1) / np.sqrt(5.95)

K_grid = np.linspace(0, 1, 21)
K_star = P_pred / (P_pred + R)    # 推导出来的最优增益
plt.plot(K_grid, (1 - K_grid)**2 * P_pred + K_grid**2 * R, 'k', label='理论 P(K)')
for kind in ['高斯', '均匀', '双峰', '重尾']:
    e_pred = np.sqrt(P_pred) * unit_noise(kind, n)   # 预测误差
    v = np.sqrt(R) * unit_noise(kind, n)             # 读数噪声
    var = [np.mean(((1 - K) * e_pred + K * v)**2) for K in K_grid]
    plt.plot(K_grid, var, 'o', ms=4, label=kind)
    best = np.mean(((1 - K_star) * e_pred + K_star * v)**2)
    print(f'{kind}: 在 K* 处实测方差 = {best:.3f}')
print(f'理论：K* = {K_star:.2f}，最小方差 = {(1 - K_star) * P_pred:.3f}')
plt.axvline(K_star, color='gray', ls=':')
plt.xlabel('K'); plt.ylabel('估计误差的方差'); plt.legend(); plt.show()

function w = unit_noise(kind, n)
    % 均值为 0、方差为 1，但形状各不相同的几种噪声
    switch kind
        case '高斯'
            w = randn(n, 1);
        case '均匀'
            w = (2 * rand(n, 1) - 1) * sqrt(3);
        case '双峰'
            w = 0.9 * sign(rand(n, 1) - 0.5) + sqrt(0.19) * randn(n, 1);
        case '重尾'               % 95% 的时候噪声很小，5% 的时候放大 10 倍
            big = rand(n, 1) < 0.05;
            w = randn(n, 1) .* (1 + 9 * big) / sqrt(5.95);
    end
end

      第 3 课 · 约 20 分钟

      单步跑一遍

      把前两课拼起来：预测让不确定性变大，观测让它变小，一步接一步地循环。下面这辆小车会陪你把五个公式挨个算一遍。

      两个阶段：预测和更新

      卡尔曼滤波的每一步都分成两个阶段，交替进行。

      预测（也叫时间更新）：第 k 步的读数还没到。只靠运动模型，把上一步的估计往前推到当前时刻，得到先验估计 和它的误差方差 。上标 − 的意思是「还没用上第 k 步的读数」。小车在这段时间里又受了一次扰动，所以不确定性变大。

      更新（也叫量测更新）：读数 到了。用它修正先验估计，得到后验估计 和它的误差方差 。用上了新的信息，所以不确定性变小。

      阶段用到的信息输入输出不确定性

      后验估计接着成为下一步预测的起点，如此循环。有的教材和论文把先验、后验写成 x̂k|k−1 和 x̂k|k，竖线后面表示「用到了截至哪一步的读数」，意思相同。

      误差方差的锯齿前 12 步：预测让它升高，更新让它降低
      预测：P⁻ = P + Q，升高 更新：P = (1 − K)P⁻，降低 两次读数之间

      参数沿用下面「一步一步算」里的设置。升高和降低的幅度很快变得相等，这时方差不再变化，滤波器进入稳态。

            • 点「初值错了，还很自信」：初值差了 6 米，√P₀ 却只有 0.3 米。开头几步 K 很小，滤波器固执地相信错误的初值，蓝线开头一段都跑在 ±2√P 的阴影外面，要过十来步才被读数拉回来。再点「完全不知道起点」：第一步 K 接近 1，估计立刻跳到读数附近。初值可以错，但 P₀ 要诚实。
            • 不管初值怎么设，P 和 K 都会忘掉 P₀，收敛到同一个稳态值。初值只影响开头那一段。
            • P 和 K 的计算只用到 Q、R 和初值，和读数 z 无关，所以它们可以提前算好。它们收敛得很快，现在的参数下 K 稳定在 左右。
            • 收敛之后，卡尔曼滤波就是一个固定权重的加权平均：每一步从预测往读数的方向挪 。
            • 蓝线大部分时间待在 ±2√P 的阴影里，说明滤波器对自己误差的估计是诚实的。进阶篇会把「诚实」变成一个可以检验的指标。
            • 把 σR 调大：K 变小，估计更平滑，但对真实变化的反应也更慢。第 7 课会从频率的角度重新看这个权衡。

              贝叶斯视角：高斯给了我们什么

              前三课只追踪两个数：估计是多少，方差有多大。这一课换一种更完整的描述，直接追踪「小车在每个位置的可能性有多大」，也就是整个概率分布。这条路推出的还是同一组公式，但它能回答一个前面回答不了的问题：卡尔曼滤波到底是不是最好的？

              用一条曲线表示「我知道多少」

              我们对小车位置的认识，可以画成一条曲线 p(x)，叫概率密度：曲线在哪里高，小车就更可能在哪里；曲线下的总面积永远是 1。曲线越窄越高，说明越有把握。

              最常用的是高斯分布 N(μ, σ2)，也就是钟形曲线：μ 是最可能的位置，σ 是不确定的程度。它只用两个数就能完全确定，这一点后面会起决定性的作用。

              贝叶斯公式：读数怎样改变认识

              读数到来之前，我们已经有一个认识，来自预测。读数到来之后，认识应该怎么变？贝叶斯公式给出了唯一合理的答案。它涉及三条曲线：

              • 先验 p(x)：读数到来之前的认识。在滤波里，它就是预测的结果。
              • 似然 p(z | x)：假如小车真的在 x，读到 z 的可能性有多大。因为 z = x + v，读到 z 就意味着噪声恰好等于 z − x，所以似然就是噪声的密度在 z − x 处的值。
              • 后验 p(x | z)：看到读数之后的认识。
              贝叶斯公式

              这里有一个容易绕晕的地方：读数 z 已经是一个确定的数了，所以要把似然看成 x 的函数，它回答的是「哪些位置能解释这个读数」。噪声是高斯时，它是一条以读数为中心、宽度为 σR 的钟形曲线。分母 p(z) 和 x 无关，只负责把面积调回 1。

              所以操作很简单：两条曲线逐点相乘，再归一化。相乘的道理是：一个位置要可信，必须既符合预测，又能解释读数。只要有一方认为它几乎不可能，乘积就接近 0。

              先验（预测）N(μ₁, σ₁²) 似然（读数）N(μ₂, σ₂²) 后验 N(μ, σ²)

              看出了什么

              • 后验永远比先验和似然都窄：用上读数之后，总是更有把握。
              • 后验的峰落在两者之间，靠向更窄、更准的那一条。两条一样宽时正好取中点。
              • 两条高斯曲线相乘，结果看起来还是一条钟形曲线。这不是巧合，下面就来证明。

              推导：更新就是两个高斯相乘

                预测在贝叶斯里是什么

                更新是「相乘」，那预测呢？预测要回答的是：已知上一步小车位置的分布，再走一步之后，位置的分布是什么？

                  所以，卡尔曼滤波是什么

                  预测用全概率公式，更新用贝叶斯公式，两步交替进行，这套做法叫贝叶斯滤波。它对任何分布、任何模型都成立，是最一般的答案：一般情形下，预测要按状态转移概率，把上一步各种可能状态的贡献加起来；在本例中，因为小车只是平移再叠加一个扰动，这一步恰好是卷积。麻烦在于，一般情况下分布的形状会越变越复杂，没法用有限的几个数存下来。

                  线性模型加高斯噪声是一个特例。在这个特例里：

                  阶段贝叶斯滤波（一般情形）线性 + 高斯时
                  预测按状态转移概率，把上一步各种可能状态的贡献加起来（本例中是平移再卷积）高斯卷积高斯还是高斯：均值加 uΔt，方差加 Q
                  更新先验乘以似然，再归一化高斯乘高斯还是高斯：均值和方差按 ③ ④ ⑤ 变化

                  只要初始分布是高斯，之后每一步的分布就永远是高斯。而高斯分布只需要均值和方差两个数就能完全确定，所以我们不必追踪整条曲线，只追踪这两个数就够了。这两个数的递推公式，正是第 3 课的五个公式。

                  这一课的核心结论

                  卡尔曼滤波是贝叶斯滤波在「线性模型 + 高斯噪声」下的精确解。第 3 课图里的钟形曲线，在高斯假设下就是真正的后验分布，不只是示意。

                  为什么报后验的均值：最小均方误差估计

                  后验是一整条曲线，可我们最终要报一个数。报哪个？这取决于怎么评价「报得好不好」。最常用的标准是均方误差：误差的平方的平均值。它越小越好；让它最小的估计叫最小均方误差估计，英文缩写 MMSE。均方根误差 RMSE 是它的平方根，让其中一个最小，另一个也最小。

                  • 不管后验是什么形状，MSE(a) 都是一条抛物线，最低点正好在后验均值 m 处，最低点的高度正好是后验方差。
                  • 任何时候都有：均方误差 = 后验方差 + (m − a)²。第一部分来自小车位置本身的不确定，报什么数都躲不掉；第二部分是报偏了多付的代价，报均值时它为 0。
                  • 切到「偏斜」：曲线的最高点不在均值处。报最高点，也就是「最可能的位置」，均方误差反而更大。
                  • 切到「双峰」：均值落在两个峰之间，那里小车几乎不可能出现，可它仍然是均方误差最小的选择。这也提醒我们，后验有两个峰时，只报一个数本身就不够。

                  推导：为什么是均值

                    换一个评价标准，答案会变

                    均值是「平方误差」这个标准下的最优。如果改成让误差绝对值的平均最小，最优的是后验的中位数；如果想报「最可能的位置」，就是曲线的最高点，叫极大后验估计（MAP），下一课专门讲它。高斯分布左右对称、只有一个峰，这三个数重合，所以高斯时不用纠结选哪个标准。

                    噪声不是高斯时会怎样

                    贝叶斯公式并不要求高斯。下面保持先验是高斯，只把读数噪声换成别的分布，方差保持不变。这时没有现成的公式，就用数值方法把两条曲线逐点相乘。再把卡尔曼滤波给出的结果画在一起，看两者差在哪。

                    高斯假设到底给了我们什么

                    现在可以完整地回答了。推出公式不需要高斯假设，第 2 课已经证明过。高斯假设给的是三样别的东西：

                    • 更强的最优性。没有高斯假设：在所有线性估计里方差最小。有高斯假设：在所有估计里均方误差最小，任何非线性的办法都不可能更好。
                    • 完整的分布。只知道方差时，能说的很有限：由切比雪夫不等式，误差落在 ±2σ 以内的概率至少是 75%。知道是高斯以后，这个概率就是 95%，可以给出准确的置信区间。
                    • 两个数就够用。分布永远保持高斯，所以只存均值和方差，就没有丢掉任何信息。

                    反过来，噪声明显不是高斯时，卡尔曼滤波仍然是最好的线性滤波器，但还有改进的空间。进阶篇的粒子滤波直接用数值方法近似整个后验；鲁棒滤波则专门对付重尾噪声和野值。

                    一句话

                    高斯假设不是推出卡尔曼滤波的前提，它决定的是这个公式有多好。

                    第 5 课 · 视角 · 极大后验 · 约 20 分钟

                    极大后验视角：找后验的最高点

                    上一课最后提到，除了报后验的均值，还可以报后验曲线的最高点，也就是「最可能的位置」。这叫极大后验估计，英文缩写 MAP。沿着这条路走，估计变成了一个求最值的优化问题；取一次对数，它就是加权最小二乘。这个视角还天然告诉我们，遇到离谱的读数该怎么办。

                    从后验的最高点到最小二乘

                      加权最小二乘

                      J 的两项可以这样读：给每个候选位置打一个「矛盾分」，离预测越远扣分越多，离读数越远也扣分越多。扣分用各自的方差做分母，所以越不准的线索，偏离它的代价越小。极大后验估计就是矛盾分最低的位置。

                      顺带一提，这个最小化问题本身并不依赖高斯：即使不谈概率分布，也可以直接把 J 当作出发点，这时它叫加权最小二乘，答案完全相同。高斯假设的作用，是告诉我们它同时也是后验的最高点。

                      两根弹簧

                      这个最小化问题有一个很直观的物理模型：小车被两根弹簧拉着，一根拴在预测位置，一根拴在读数位置，劲度分别是 1/P⁻ 和 1/R。弹簧的弹性势能和拉伸量的平方成正比，所以 J 就是两根弹簧的总势能，小车停下来的平衡点就是 J 的最小点。

                      两根弹簧拉着小车弹簧越粗，劲度越大，也就是那条线索越准
                      后验 p(x | z)正比于 exp(−J/2)
                      取负对数：J(x)后验的最高点，正对着 J 的最低点
                      偏离预测的代价 偏离读数的代价 总代价 J(x) 最小点 = 估计
                      平衡点 x̂
                      总劲度 1/P⁻ + 1/R
                      融合后的方差 P
                      被读数拽离预测的距离

                      看出了什么

                      • 后验的最高点、J 的最低点、弹簧的平衡点，三者是同一个位置。求最大的后验和求最小的 J 是一回事。
                      • 这个位置就是第 2 课的 x̂。劲度大的弹簧，也就是更准的那条线索，把小车拉得更近。
                      • 两根弹簧一起拉，总劲度是两者相加：1/P⁻ + 1/R。总劲度越大，小车越难被推离平衡点，这就是「精度相加」。融合后的方差 P 就是总劲度的倒数。
                      • 点「读数离谱」，再在两种弹簧之间切换。普通弹簧拉得越长、力越大，一个差了 8 米的读数能把小车拽走 4 米。Huber 弹簧拉过一定长度后，力就不再增加，小车只被拽走 1.3 米左右。把平方损失换成对野值不敏感的损失，就是基于 M 估计的鲁棒滤波的出发点。Huber 损失就是 M 估计里最常用的一种。
                      • 从极大后验的角度看，换弹簧就是换噪声模型：损失函数是噪声密度的负对数。平方损失对应高斯噪声；Huber 损失对应一种中间像高斯、两边尾巴更重的噪声。认为噪声的尾巴越重，损失增长得就越慢，估计对野值也就越不敏感。切换到 Huber 弹簧时，上面的后验曲线也跟着变了。

                        三件事：数值求最小点并与公式对比；用一个野值对比平方损失和 Huber 损失；验证车不动时，逐步递推的卡尔曼滤波和一次性的加权最小二乘结果完全相同。

                        import numpy as np

# 1. 加权最小二乘：数值求最小点，和公式对比
x = np.linspace(0, 30, 300001)
J = (x - x_pred)**2 / P_pred + (z - x)**2 / R
K = P_pred / (P_pred + R)
print(f'数值最小点 {x[J.argmin()]:.3f}，公式给出 {x_pred + K * (z - x_pred):.3f}')

# 2. 读数是个离谱的野值：平方损失 vs Huber 损失（只换掉读数那根弹簧）
def huber(r, c=1.345):
    return np.where(np.abs(r) <= c, r**2 / 2, c * np.abs(r) - c**2 / 2)
P_pred2, z_bad = 1.0**2, 18.0      # 这次预测更有把握一些，读数却差了 8 m
J_sq = (x - x_pred)**2 / P_pred2 + (z_bad - x)**2 / R
J_hub = (x - x_pred)**2 / P_pred2 + 2 * huber((z_bad - x) / np.sqrt(R))
print(f'野值 z = {z_bad}：平方损失给出 {x[J_sq.argmin()]:.2f}，Huber 损失给出 {x[J_hub.argmin()]:.2f}')
